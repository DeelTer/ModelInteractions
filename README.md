# Model Interactions

Клиентский Fabric-мод для Minecraft **26.2 / 26.3**: физическое взаимодействие с моделями
[Customizable Player Models](https://github.com/tom5454/CustomPlayerModels) на ПК и в VR
([Vivecraft](https://github.com/Vivecraft/VivecraftMod)).

- схватить и оттянуть уши, хвост, волосы, лапки — после отпускания часть пружинит обратно;
- физика зависит от типа, длины и жёсткости элемента; уши и хвосты реагируют на ходьбу, прыжки и повороты;
- VR: хват триггером/грипом, касания руками толкают части, вибрация растёт с натяжением; жесты «погладить» и «обнять»
  движением рук включаются в настройках;
- поглаживание: уши прижимаются, хвост виляет, сердечки, плюс CPM-анимация `pet` у владельца, если она есть в его
  модели;
- деформации можно сохранить (тап Shift, пока держишь часть; в VR вторая кнопка) или сбросить (K); отпустить без этого
  значит вернуть часть в исходную позу;
- разрешения: всем / белый список / никому, отдельно по частям, гладить, обнимать, оставлять форму; чёрный список.

## Зависимости

|                           | обязательно | опционально                                            |
|---------------------------|-------------|--------------------------------------------------------|
| Fabric Loader, Fabric API | ✔           |                                                        |
| CPM ≥ 0.6.27              |             | модели CPM на игроках, синхронизация через CPM         |
| Vivecraft                 |             | VR-функции                                             |
| ModMenu + Cloth Config    |             | экран настроек (иначе `config/modelinteractions.json`) |

Без CPM работают ванильные модели: игроки и любые мобы (части определяются по именам: `left_ear`, `tail`, `wing`…).

## Сервер

Два способа увидеть друг друга:

1. **Плагин Paper** `plugin/build/libs/modelinteractions-paper-*.jar` (рекомендуется). Пересылает действия игрокам в радиусе
   `range` (16 блоков) от того, кого трогают, и разрешения/позы в радиусе `state-range`. Настройки — `config.yml`.
2. **Этот же мод на сервере Fabric** или хост мира по локальной сети: те же правила и проверки, что в плагине.
   Настройки — `config/modelinteractions-server.json`. Прав (permissions) здесь нет, всё настраивается этим файлом.
3. **CPM на сервере** — без плагина, через plugin messages CPM, без проверок дистанции.

Что проверяет плагин: отправителя ставит сервер (подделать нельзя); каждое сообщение полностью разбирается и
ограничено по размеру; лимиты частоты на игрока; цель должна существовать в том же мире в пределах `reach` от глаз;
перемещение/отпускание принимается только для захвата, который игрок начал; кто может трогать (режим, белый и чёрный
списки) проверяет сервер, а сами списки другим игрокам не отправляются; позы и типы частей сервер пересобирает из
разобранных значений. Что можно трогать (уши, хвост…) проверяет каждый клиент по флагам владельца.

## Управление (ПК)

| Ввод                            | Действие                                                                                                                                    |
|---------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|
| **ПКМ** (удерж.) по части       | схватить и тянуть; колесо — к себе/от себя; тап Shift — сохранить форму                                                                             |
| **Shift + ПКМ** (удерж.)        | гладить                                                                                                                                     |
| **J**                           | обнять (до 2 блоков)                                                                                                                        |
| **K**                           | сбросить свои деформации и заставить всех отпустить                                                                                         |
| `/mi freemode` или своя клавиша | «позируй меня»: всё, что другие отпустили **на вас**, остаётся на месте. Включает только сам игрок; **K** сбрасывает позу и выключает режим |

ПКМ мимо модели работает как обычно. Отдельные клавиши «схватить» и «гладить» можно назначить в управлении
(по умолчанию не назначены; H занят меню жестов CPM). Хватание ПКМ отключается в настройках.

На ПК тянуть можно одну часть за раз, в VR — две (по одной в каждой руке). Чтобы вас поставили в позу,
включите «позируй меня» — тогда части можно расставлять по очереди.

Схватить туловище (не уши/лапы, а сам корпус) — поворот и наклон всего тела целиком, до переворота. Нужно
разрешение «Поворот моего туловища».

VR-толчки: рука, проходящая сквозь часть, толкает её; толчок передаётся по цепочке и в туловище, с учётом
веса (объёма) — лёгкое ухо отлетает, тяжёлое тело еле качнётся. Работает и на мобах.

## Типы частей своей модели

Посмотрите на часть (F5 для своей модели) и выполните `/mi part set <тип>`, вернуть автоопределение — `/mi part clear`.
Для своей модели выбор хранится в `ownTypes` конфига и рассылается всем игрокам с модом; для чужой — видите только вы.
Тип `JELLY` — мягкие части тела (грудь, живот): мелкое быстрое колыхание. Трогать их можно, только если владелец
включил разрешение «Мягкие части тела».

## Отладка без второго клиента

| Команда                                    | Что делает                                                                                                                                |
|--------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------|
| `/mi dummy spawn <модель> [имя]`           | фейковый игрок перед вами, только на вашем клиенте; модели: `rana`, `lucifer` и любые `*.cpmmodel` из `config/modelinteractions/dummies/` |
| `/mi dummy motion still\|walk\|spin\|jump` | движение манекена — проверить инерцию ушей/хвоста                                                                                         |
| `/mi dummy spawn steve`                    | манекен с обычной моделью (без CPM)                                                                                                       |
| `/mi dummy mob <тип>`                      | моб только на вашем клиенте, например `fox`, `wolf`, `allay`                                                                              |
| `/mi dummy pose on\|off`                   | манекены в режиме «позируй меня»                                                                                                          |
| `/mi dummy reset`                          | сбросить позы манекенов                                                                                                                   |
| `/mi dummy clear`                          | убрать манекенов                                                                                                                          |
| `/mi debug parts`                          | контуры частей частицами: уши розовые, хвост оранжевый, волосы фиолетовые, крылья голубые, лапы зелёные, голова жёлтая                    |
| `/mi debug rigs`                           | список ригов и сколько частей каждого типа найдено                                                                                        |

Манекену разрешено всё, по сети с ним ничего не отправляется. Настройки безопасности CPM для манекенов разрешаются
автоматически (в памяти; на диск CPM запишет их, только если сам сохранит конфиг).

## Для авторов моделей

Экспортированные модели CPM не содержат имён элементов, поэтому тип части определяется по геометрии
(`PartClassifier`): плоские элементы над головой — уши, свисающие сзади — волосы, сзади-снизу корпуса — хвост и т.д.
Если что-то определилось неверно: включите *Отладка: часть под прицелом*, посмотрите id элемента и ключ модели и
добавьте в конфиг:

```json
"overrides": { "<model key>": { "48": "ACCESSORY", "17": "EAR" } }
```

Типы: `EAR, TAIL, HAIR, WING, JELLY, LIMB, HEAD, ACCESSORY, STATIC`. Проще — командой `/mi part set`.

Командные анимации `pet`, `hug`, `grabbed` (имена настраиваются) проигрываются на модели владельца при реакции.

## Как это устроено

- `mixin/RedirectHolderMixin` — хвост `RedirectHolder.bindFirstSetup` в CPM: CPM только что сбросил и проанимировал
  все элементы, мы снимаем их позу (`CpmHooks.capture`) и добавляем поворот от пружин (`CpmHooks.apply`).
- `PlayerRig` — кости модели игрока + пружины (`SpringJoint`, неявный Эйлер, вектор поворота в системе родителя).
- `InteractionManager` — раз в кадр (`GameRendererMixin`) считает model→world, цели захватов, касания, шаг физики.
- Сеть (`net/Protocol`): по сети передаются только намерения и редкие точки цели (≈12 Гц, 1 см порог)
  в пространстве модели цели; физику каждый клиент считает сам. Разрешения и сохранённая поза — state-сообщения CPM,
  которые сервер переотправляет новым наблюдателям. Разрешения проверяет каждый клиент.

## Сборка

```bash
./gradlew build
```

Jar-файлы: `versions/26.2/build/libs`, `versions/26.3/build/libs`, плагин — `plugin/build/libs`. Тесты (`./gradlew test`) парсят тестовые модели
из `src/test/resources/models` реальными классами CPM и проверяют классификацию.
