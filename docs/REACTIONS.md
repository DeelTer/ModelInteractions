# Реакции модели на касания

Модель может отвечать на прикосновения: улыбаться, когда её гладят, хмуриться, когда тянут.
Мод сообщает **что делают** (гладят, держат, касаются…) и **номер элемента**, которого касаются.
Что это за элемент (ухо, хвост, четвёртая нога), мод не знает и не угадывает: это знаете только вы.

## Быстрый старт (CPM, 2 минуты)

1. Откройте модель в редакторе CPM и создайте анимацию (жест или слой-переключатель) с лицом «^_^».
2. Назовите её **`mi_pet`**.
3. Готово: пока вас гладят (где угодно), анимация включена, а через ~1,5 с после конца выключается.

Хотите реакцию только на конкретную часть, например на ухо? Введите `/mi debug touches` и погладьте это
ухо на себе или на манекене: мод покажет его номер, например `mi_pet_part17`. Так и назовите анимацию.

Для **Figura** — событие `modelinteractions.touch`, см. [раздел Figura](#figura).

Выключается в настройках: *Реакции → Реакции на касания*.

## Как устроено «касание»

На ПК касание — это удержание кнопки, а в VR рука просто водит по модели. Мод сводит оба случая к
одному: **касание начинается**, пока длится, у него обновляется **сила** (0…1), потом оно **заканчивается**.

| Вид (`kind`) | Что это                                          | Когда заканчивается                          |
|--------------|--------------------------------------------------|----------------------------------------------|
| `grab`       | держат часть (ПКМ на ПК, триггер/грип в VR)      | когда отпустили                              |
| `pet`        | гладят (Shift+ПКМ на ПК, жест в VR)              | ~1,5 с после последнего поглаживания         |
| `touch`      | рука в VR касается или водит по части            | ~0,4 с после того, как рука ушла             |
| `hit`        | удар пустой рукой на ПК                          | ~0,5 с                                       |
| `slap`       | резкий шлепок рукой в VR                         | ~0,7 с                                       |
| `hug`        | объятие (вся модель, без части)                  | ~2,5 с                                       |

Если рука в VR переехала с уха на голову, это **новое** касание: старое закончится, начнётся новое.

**Сила (`strength`):**

- `grab`: насколько сильно тянут, то есть насколько рука ушла от точки, где часть на самом деле держится.
  Жёсткая часть почти не поддаётся, и сила быстро растёт до 1;
- `touch`: скорость руки;
- `pet`, `slap`, `hug`: 1; `hit`: 0,7.

## CPM: анимации `mi_*`

Создайте в редакторе CPM анимацию с нужным именем (тип **Жест/Pose** или **Слой-переключатель**). Пока
касание длится, анимация включена; закончилось — выключена. Если анимации нет, ничего не происходит.

### Имена

Мод перебирает имена **от точного к общему** и включает первое, которое есть в модели:

1. `mi_pet_part17`: именно этот элемент (номер покажет `/mi debug touches`; у ванильных моделей вместо
   `part17` стоит имя части, например `mi_pet_left_ear`);
2. `mi_pet_head`: к какой части игрока прикреплён элемент: `head`, `body`, `left_arm`, `right_arm`,
   `left_leg`, `right_leg`. Это мод знает точно: так устроена любая CPM-модель;
3. `mi_pet`: любое поглаживание.

Для торса: `mi_grab_body` → `mi_grab`, а объятие всегда `mi_hug`.

Примеры:

| Хочу                                              | Имя анимации       |
|---------------------------------------------------|--------------------|
| смущение при любом поглаживании                   | `mi_pet`           |
| «^_^», когда гладят ухо (это элемент №17)         | `mi_pet_part17`    |
| грустное лицо, когда тянут за хвост (элемент №42) | `mi_grab_part42`   |
| реакция на любое касание головы и всего на ней    | `mi_touch_head`    |
| реакция на объятие                                | `mi_hug`           |

Если ухо — это несколько элементов, сделайте анимацию на каждый номер (они могут быть одинаковыми) или
просто используйте `mi_pet_head`.

### Как узнать номер части

Введите `/mi debug touches` и попросите кого-нибудь потрогать вас (или потрогайте манекен с той же моделью:
положите `.cpmmodel` в `config/modelinteractions/dummies/` и `/mi dummy spawn <имя файла>`).
На каждое новое касание мод покажет над хотбаром и запишет в лог список имён, например:

```
Steve → Alex: mi_pet_part17 / mi_pet_head / mi_pet  ▶ mi_pet
```

После `▶` указана анимация, которая сработала (только на вас: на манекене анимации не включаются, он лишь показывает имена). Повторный `/mi debug touches` выключает вывод.

### Сила: слой значения

Для плавной реакции создайте **Слой значения (Value layer)** с именем `mi_<вид>_value`: `mi_grab_value`,
`mi_touch_value`, `mi_pet_value`. Значение 0…255 — самое сильное касание этого вида сейчас (пока касание
идёт, не меньше 1). Например, `mi_grab_value` может плавно сдвигать брови: чем сильнее тянут, тем
сильнее хмурится.

### Кто это видит

Анимации включает **ваш собственный клиент**, а другим игрокам их передаёт сам CPM, как обычные жесты.
Поэтому реакцию увидят все, у кого стоит CPM, даже без этого мода.

> Старые «Анимация поглаживания / объятия / захвата» из настроек (`pet`, `hug`, `grabbed`) работают как раньше.

## Figura

Если установлена Figura, у каждого аватара появляется событие `modelinteractions.touch`. Ставить
в зависимость не нужно: без Figura мод работает как обычно.

```lua
events["modelinteractions.touch"]:register(function(t)
  -- t.phase    "start" | "update" | "stop"
  -- t.kind     "grab" | "pet" | "touch" | "hit" | "slap" | "hug"
  -- t.part     "part17", "left_ear" или "body"
  -- t.bone     номер части (число)
  -- t.region   к чему прикреплён: "head", "body", "left_arm", "right_arm", "left_leg", "right_leg"
  -- t.strength 0..1
  -- t.hand     0 или 1 (какой рукой, в VR)
  -- t.actor     UUID того, кто трогает (строка)
  -- t.actorName ник того, кто трогает
  -- t.self     true, если трогают вас (этот клиент — владелец аватара)
  -- t.byMe     true, если трогает этот клиент
end)
```

Событие приходит **на каждом клиенте**, который видит касание. Пинги не нужны: все, у кого стоит мод,
сами вызовут его у вашего аватара. `update` приходит не чаще ~10 раз в секунду и только при заметном
изменении силы.

### Пример: «^_^», пока гладят голову

```lua
local happy = 0

events["modelinteractions.touch"]:register(function(t)
  if t.kind == "pet" and t.region == "head" then
    if t.phase == "start" then happy = happy + 1 end
    if t.phase == "stop"  then happy = math.max(0, happy - 1) end
    animations.model.happy:setPlaying(happy > 0)
  end
end)
```

Счётчик нужен на случай, если гладят двое одновременно: лицо вернётся, только когда закончат оба.

### Пример: хмуриться, когда тянут за элемент №42 (хвост), по силе натяжения

```lua
events["modelinteractions.touch"]:register(function(t)
  if t.kind == "grab" and t.part == "part42" then
    local s = t.phase == "stop" and 0 or t.strength
    models.model.Head.Brows:setRot(0, 0, s * 20)
  end
end)
```

### Важно для Figura

- Части определяются по **ванильной** модели игрока (голова, тело, руки, ноги) или по CPM-модели, если она есть.
  Свои части Figura мод не видит, поэтому для чистого Figura-аватара ориентируйтесь на `t.region`.
- Мод работает с Figura через внутренние классы; если версия Figura их изменит, в логе будет
  «This Figura version is not supported», а события перестанут приходить. Остальное продолжит работать.

---

## Разрешения

Событие приходит только для касаний, которые владелец модели разрешил: тот же режим, белый/чёрный список и
флаги частей. Запрещённое касание модель не «чувствует».

## Совместимость

Поглаживание теперь передаёт часть. Старые версии мода игнорируют её, а от них поглаживание приходит
как «вся модель» (`mi_pet_body` → `mi_pet`).
